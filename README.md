1️⃣ Project A: Automated E-Commerce Catalog Scraper
Folder: 01_catalog_scraper/

Tech Stack: Python, BeautifulSoup4, requests, pandas, openpyxl

Overview: A robust web scraping pipeline that dynamically navigates multi-page product listings, performs regular expression (re) text sanitization, handles rate-limiting, and outputs formatted Excel datasets.

2️⃣ Project B: Executive Sales & Revenue Analytics Dashboard
Folder: 02_sales_dashboard/

Tech Stack: Python, Streamlit, Plotly, pandas

Overview: An interactive web dashboard for real-time business intelligence. Displays key performance metrics (KPIs), profit margin analyses, and category sales distributions with interactive visualizations.

3️⃣ Project C: Automated Competitor Price Tracker & Alert Bot
Folder: 03_price_tracker/

Tech Stack: Python, pandas, datetime

Overview: An automated monitoring engine that simulates real-time price tracking across competitor e-commerce catalogs, calculates variance against threshold target prices, and triggers immediate alerts upon detecting price drop breaches.
